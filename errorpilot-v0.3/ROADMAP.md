# Roadmap

These are **proposed** milestones, not released functionality.

## v0.4 — stronger diagnostics

- Better import-name to distribution-name mapping
- More precise environment and dependency analysis
- Test runner integration and richer verification evidence
- Reproducible real-world failure fixtures

## v0.5 — safe code patch proposals

- Generate proposed source patches for selected error classes
- Display diffs and request explicit approval
- Backup/restore on unsuccessful verification
- Run focused tests and report changed behavior

## v0.6 — optional local intelligence

- Optional Ollama-backed explanation and patch suggestions
- Fully offline mode when model and dependencies are available locally
- Additional editor/CI integrations
- More languages and framework-aware diagnostics, subject to design review

## Non-goals for v0.3

General autonomous code editing, guaranteed logic bug repair, sandboxed untrusted execution, and production security auditing.
