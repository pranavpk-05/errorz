# Changelog

## 0.3.0 — current

- Added `auto` workflow for static checks, trusted script execution, traceback classification, and opt-in dependency repair.
- Added project-local interpreter discovery and isolated virtual-environment creation for eligible repairs.
- Added verification by rerunning the original script after installation.
- Added Windows setup and launcher scripts, JSON diagnostics, and pytest/CI coverage.

## Documentation refresh

- Reorganized README for GitHub publishing.
- Added getting-started, CLI usage, architecture, diagnostics, troubleshooting, development, contribution, and security guides.
- Added GitHub issue and pull request templates.

This documentation refresh does not change the CLI's version or claim new runtime repair capabilities.
